# Мой трекер

Лёгкий веб-сайт-инструмент для себя: настраиваете, что хотите отслеживать, и ведёте записи с телефона.

**Разделы (включаются и сортируются в настройках):**

- 💶 **Финансы** — расходы и доходы, категории, наличные и свои карты; итоги за неделю/месяц/год, разбивка по категориям и картам.
- 🏋️ **Тренировки** — библиотека из ~170 упражнений и тренажёров, свои упражнения; программы по дням недели и времени (есть шаблоны); экран тренировки с таймером, подходами, таймером отдыха и подсказкой «как в прошлый раз»; рекорды и прогресс.
- 🚬 **Курение** — запись в одно касание, что именно курил, дневной лимит, статистика, покупки пачек сразу в расходы.
- 🛒 **Покупки** — «мой набор» продуктов для дома, список «что купить», оформление чека с ценами → расход в финансах.
- 🩺 **Врачи** — записи к врачам, мои врачи, итоги визитов, стоимость в расходы, выгрузка события в календарь телефона (с напоминаниями).
- ✨ **Свои трекеры** — любые поля: число, деньги, текст, список, да/нет, оценка, длительность. Заготовки: вес, сон, вода, настроение, лекарства, кофе, алкоголь, чтение, авто.

Плюс общий календарь, лента истории, быстрая кнопка «+», светлая/тёмная тема, работа офлайн и установка на домашний экран.

## Где хранятся данные

Только в браузере на устройстве (IndexedDB), ничего никуда не отправляется. Поэтому:
- на разных устройствах данные разные;
- делайте резервную копию: **Настройки → Сохранить резервную копию** (JSON-файл), восстановление — там же.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из консоли. Чтобы открыть с телефона в той же Wi-Fi сети — используйте адрес `Network: http://192.168.…:5173`.

## Публикация

```bash
npm run build
```

Папка `dist/` — готовый статичный сайт. Её можно выложить на любой хостинг статики (GitHub Pages, Netlify, Cloudflare Pages, Vercel). Для установки на телефон и работы офлайн нужен HTTPS (все перечисленные хостинги дают его бесплатно).

На телефоне: откройте сайт → iPhone: «Поделиться» → «На экран «Домой»; Android: меню → «Установить приложение».
